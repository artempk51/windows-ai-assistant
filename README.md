# 🤖 Windows AI Assistant (Jarvis-like Bot)

Кастомный голосовой ИИ-помощник для Windows на базе Python. 
Программа работает в полностью автономном фоновом режиме, вызывается глобальным шорткатом `Ctrl + Alt + Space` и позволяет управлять системой с помощью естественного языка.

В основе проекта лежит интеграция с нейросетью **Google Gemini**, что позволяет помощнику понимать даже неточные или свободные формулировки пользователя.

## ✨ Ключевые возможности

* 🧠 **Умное распознавание (AI):** Интеграция с API Google Gemini. Если команда не найдена в базе, ИИ сам переводит естественный язык в нужный системный скрипт.
* 🎙️ **Голосовое сопровождение:** Озвучка действий с помощью встроенного системного синтезатора Windows (на английском языке) в стиле Джарвиса.
* 👻 **Невидимый режим:** Работает в фоне без окна консоли (`.pyw`), автоматически запускается при старте ПК.
* 💬 **Интеграция с Telegram:** Автоматический поиск контактов и отправка сообщений через буфер обмена (`Shift + Insert`).
* 🌍 **Умный переводчик:** Быстрый перевод фраз без открытия браузера с мгновенным копированием в буфер обмена.
* 📸 **Скриншоты и Видео:** Создание снимков экрана и запуск записи видео (Xbox Game Bar) по одной команде.
* ⏱️ **Продуктивность:** Фоновые таймеры с поверхностными (Topmost) уведомлениями и быстрое создание заметок в `.txt` на Рабочем столе.
* ⚙️ **Системные команды:** Управление звуком, смена светлой/темной темы Windows, очистка корзины, блокировка ПК и запуск установленных программ.

## 🛠️ Стек технологий

* **Язык:** Python 3
* **GUI:** `tkinter` (создание минималистичного виджета ввода)
* **Горячие клавиши:** `keyboard` (глобальный перехват и симуляция нажатий)
* **ИИ:** `google-generativeai` (Gemini 3.8 Flash)
* **Система:** `os`, `subprocess`, `ctypes`, `mss` (захват экрана)
* **Многопоточность:** `threading` (чтобы таймеры и голос не фризили основной виджет)
